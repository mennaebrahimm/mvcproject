# E-Commerce Website 🛒

## 📌 Overview
This project is an **E-Commerce Website** designed to provide a smooth and user-friendly experience for browsing, filtering, and purchasing organic crops online.

The platform includes both **customer-facing features** and a powerful **admin panel** for managing products and sales efficiently.

---

## 💡 Key Features

### 🛍 Customer Features
- User-friendly interface for browsing organic crops
- Product filtering and searching
- Easy and secure purchasing process
- Responsive design for different devices

### 🛠 Admin Panel
- Full control over products (Add / Edit / Delete)
- Sales tracking and reporting
- Inventory management
- Order monitoring and management

---

## 🛠 Technologies Used
- **ASP.NET MVC**
- **Entity Framework**
- **SQL Server**
- **Bootstrap**
- **JavaScript**

---

## 🎯 Project Goals
- Provide a simple and intuitive online shopping experience
- Support organic product sellers with efficient management tools
- Ensure scalability and maintainability using MVC architecture
